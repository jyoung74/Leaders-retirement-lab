# 리더스 은퇴설계 연구소 — 프리미엄 리뉴얼 시안

- 모바일 우선 반응형 정적 홈페이지
- 은퇴자금 간편 계산기
- 소개 / 은퇴설계 / 인사이트 / 문의 섹션
- 파일: index.html, styles.css, script.js

## GitHub 반영 방법
기존 저장소에서 같은 이름의 파일을 각각 열어 편집(연필) 후 전체 내용을 교체하거나,
파일 목록에서 기존 파일을 삭제하고 같은 이름으로 새 파일을 업로드하세요.
파일명은 반드시 소문자 `script.js`로 유지합니다.
