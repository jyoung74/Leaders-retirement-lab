# 리더스 은퇴 연구소 홈페이지 (초기 버전)

모바일 우선 반응형 정적 홈페이지입니다. 별도 설치 없이 `index.html`을 열면 미리 볼 수 있습니다.

## 포함 기능
- 모바일 메뉴
- 은퇴자금 간편 계산기
- 회사/서비스 소개 섹션
- 이메일 문의 링크(예시 주소이므로 실제 주소로 교체 필요)

## 배포 전 반드시 확인할 사항
1. `index.html`의 `hello@example.com`을 실제 상담 이메일로 변경합니다.
2. 사업자 정보, 운영자 정보, 개인정보 처리방침, 이용 안내를 추가합니다.
3. 계산 결과는 물가상승률·투자수익률·세금 등을 반영하지 않은 단순 참고치임을 명확히 안내합니다.
4. 고객의 민감한 금융정보를 저장하는 기능은 아직 구현되어 있지 않습니다. 저장 기능을 추가하기 전 개인정보 보호 및 보안 설계를 별도로 진행해야 합니다.
